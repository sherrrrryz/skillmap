# Skill Map

Learn what an AI agent skill is, then take one apart and rebuild it.

- **index.html**: Skill Lab. What a skill is, how people write and automate them, plus a tool that checks a SKILL.md against the spec.
- **canvas.html**: Skill Canvas. Breaks a SKILL.md into cards on a canvas. Drag, edit and reorder them, then export the map as a new SKILL.md.

Everything runs in the browser. Nothing is uploaded.
