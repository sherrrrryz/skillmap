# Skill Map

Learn what an AI agent skill is, then take one apart and rebuild it.

**Live site:** https://sherrrrryz.github.io/skillmap/

- [Skill Lab](https://sherrrrryz.github.io/skillmap/) (`index.html`): What a skill is, how people write and automate them, plus a tool that checks a SKILL.md against the spec.
- [Skill Canvas](https://sherrrrryz.github.io/skillmap/canvas.html) (`canvas.html`): Breaks a SKILL.md into cards on a canvas. Drag, edit and reorder them, then export the map as a new SKILL.md.

Everything runs in the browser. Nothing is uploaded.
